# Roadmap

## P0 production foundation

- stateless credential BFF
- Redmine issue/meta/attachment/time-entry adapter
- installable React/Mantine PWA
- IndexedDB issue/attachment cache
- durable offline outbox
- reconnect/manual sync
- my-work list and dynamic issue detail
- comments/private notes
- status/field updates
- camera + attachment upload/cache
- MapLibre map and native navigation
- Compose + optional Caddy
- CI/build/tests/health/security headers

## P1 field usability

- conflict resolution polish
- richer relationship/subissue editing
- online issue creation
- saved filters UI
- tracker exclusions
- attachment storage budgeting
- optional municipality/radius offline map downloader
- notification preference UI and integration adapter

## P2 integration

- Web Push delivery integration compatible with stateless core (external subscription/event adapter or Redmine-side integration)
- saved Redmine query import where feasible
- advanced map clustering/work planning

## Future separate capability

- full electronic Rapportzettel/timekeeping system with a dedicated backend if Redmine is insufficient
