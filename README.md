# Derkumpel

Offline-first, touch-optimierter PWA-Client für Redmine im kommunalen Bauhof.

Derkumpel nutzt Redmine als führendes System, ergänzt aber eine auf Außendienst und Smartphone optimierte Oberfläche mit lokalem Offline-Cache, Synchronisationswarteschlange, Kartenansicht, Kamera-/Anhangsworkflow und schlankem stateless Backend/BFF.

Der aktuelle Zielstand ist in `docs/PRODUCT_SPEC.md` beschrieben. Entwicklungsagenten lesen zuerst `AGENTS.md` und die dort referenzierten Dokumente.
